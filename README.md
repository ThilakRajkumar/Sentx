# ⚔️ Sentx: AI-Powered Malware & URL Threat Scanner

**Sentx** is a lightweight yet powerful web-based tool designed to scan files and URLs for potential malware using the **VirusTotal API**.  
It helps researchers, analysts, and developers quickly detect and verify malicious content in real time.

---

## 🧠 Description

**Sentx** integrates with the **VirusTotal public API** to analyze suspicious files or URLs by sending them for remote scanning.  
The tool provides a simple and clean web interface built using **Flask (Python)**, making malware detection easy, fast, and visually appealing.

---

## 🚀 Features

✅ **Dual Mode Scanning**
- Scan both **Files** and **URLs** for potential malware threats.  

✅ **Real-Time Results**
- Instantly fetch and display threat detection results from VirusTotal.  

✅ **User-Friendly Interface**
- Built with a minimalistic and intuitive UI for ease of use.  

✅ **VirusTotal Integration**
- Uses your personal VirusTotal API key for fast and accurate detection.  

✅ **Cross-Platform**
- Works on **Windows, macOS, and Linux** with Python 3.  

---

## 🧩 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Flask Templates)  
- **Backend:** Python (Flask Framework)  
- **API:** VirusTotal API v3  
- **Version Control:** Git & GitHub
